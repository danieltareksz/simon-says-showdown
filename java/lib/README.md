# Libraries

The game needs one library, **jSerialComm 2.10.4**, to open the USB serial port of the laptop's XBee.

`jSerialComm-2.10.4.jar` is committed in this folder, so everyone builds with the same version and there is nothing to download. It came from:

https://repo1.maven.org/maven2/com/fazecast/jSerialComm/2.10.4/jSerialComm-2.10.4.jar
